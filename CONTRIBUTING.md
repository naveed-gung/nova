# Contributing to Nova

Thanks for contributing to Nova.

## Workflow
- Use a short-lived branch for each issue or change slice.
- Keep pull requests small and focused.
- Link the related issue in the pull request description.

## Local setup
1. Install dependencies.
2. Configure the required environment variables for voice, language, and AI services.
3. Start the local development server.

## Validation
Run the smallest relevant validation before opening a pull request.
- Docs or workflow-only changes: review Markdown and template rendering.
- App changes: run the project build.
- Integration checks: run the local dev flow when the change affects behavior.

## Pull request expectations
- Summarize the change clearly.
- Note any language or API assumptions.
- Add screenshots for UI changes when relevant.
- Split unrelated work into follow-up issues.
